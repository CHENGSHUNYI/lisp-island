# 🏝️ 鄭霸的LISP分類島導覽

AutoCAD LISP 指令的互動式分類地圖。每個分類是一座島，點選島嶼即可瀏覽該分類的指令、查看功能說明與操作方式，並下載 `.fas` 檔。

## 功能
- 3D 島嶼地圖（Three.js）：海浪起伏、島嶼漂浮、樹木雲朵飛鳥；可拖曳旋轉、滾輪縮放，點島嶼鏡頭會飛過去
- 每座島都有一位職人代表，會輪流跳出來喊「選我！」介紹自己的島；滑鼠移到島上時也會喊
- 右上角可切換 2D / 3D；瀏覽器不支援 WebGL 時自動使用 2D 地圖
- 島的大小代表該分類的指令數量
- 全站搜尋（可輸入多個關鍵字，以空白分隔），地圖會標出每座島的符合數量
- 依難易度、LT 2024+ 支援度篩選，或只顯示可下載的指令
- 每支指令都有自己的網址（`#id=序號`），方便分享
- `系統/授權` 分類只顯示說明，不提供下載

## 更新資料
資料來自上一層資料夾的 `LSP功能說明清單.xlsx`。修改 Excel 後執行：

```
python build.py
```

這會重新產生 `data.js` 和 `fas/` 資料夾，然後 commit 並 push。
修改 `app.js`、`map3d.js` 或 `style.css` 後，請把 `index.html` 裡的 `?v=` 數字加一，讓訪客的瀏覽器載入新版。

要加教學影片：在 Excel「功能說明清單」工作表新增一欄 **影片網址**，填入 YouTube 網址後重新執行 `build.py`。
